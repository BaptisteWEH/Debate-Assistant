# 🇬🇧 English Version

## 📌 Project Overview
**Debate Assistant** is an interactive web application designed to help users evaluate, analyze, and improve their debate skills (oral or written).

The application allows users to upload debate speeches or transcripts, receive structured AI-generated feedback based on custom evaluation rubrics, and chat in real-time with an AI debate coach.

---

## 🛠️ Tech Stack & Key Learnings

### 🧠 AI & Backend Engineering
* **RAG (Retrieval-Augmented Generation):** Built a RAG pipeline to inject context (evaluation rubrics, debate rules, reference documents) into LLM prompts for grounded, accurate feedback.
* **LangChain:** Utilized LangChain to chain prompts, manage conversation memory, and structure AI agent interactions.
* **LLM Integration:** Direct integration with LLM APIs for feedback generation, scoring, and interactive coaching.
* **Database (MongoDB):** Integrated MongoDB to store session data, evaluation rubrics, debate histories, and user metadata.

### ☁️ Cloud & Infrastructure (AWS)
* **AWS S3:** Storage for audio uploads, transcripts, and generated artifacts.
* **AWS EC2:** Cloud server instance used for hosting and deploying the backend services.

### 💻 Frontend & UI
* **Next.js (React), TypeScript, TailwindCSS:** Modern web interface (largely built with AI assistance to rapidly iterate on UI while focusing on core backend engineering).

---

## ✨ Key Features
- 📤 **Upload & Analysis:** Process debate recordings or transcripts.
- 📊 **Rubric Evaluation:** Automated scoring and qualitative feedback based on debate criteria (argumentation, structure, rebuttal, delivery).
- 💬 **Interactive AI Coach:** Real-time chat assistant providing targeted recommendations.
- 📜 **Debate History:** Track scores and progression over time.
